🎓 THE BATCHMATES

Feature Specification Document: Major Auto-Group & Teacher Assignment System
Version: 1.0 | Project: The Batchmates Social Platform

1. 📌 Executive Summary

The Major Auto-Group & Teacher Assignment System is an automated academic feature for The Batchmates. Whenever a student sets their Major (e.g. Computer Science) and Graduating Year (e.g. 2026) on their profile, the system automatically enrolls them into their corresponding department class group.

2. 💡 Core Features

  • Auto Enrollment Profile update triggers instant group placement with zero manual invite links.
  • Dual Tab Group 📌 Official Teacher Desk (Assignments & Notices) + 💬 Student Discussion Hub.
  • Submission Portal Students view deadlines and upload solution PDFs directly.
  • Teacher Verification Distinctive 👨‍🏫 Verified Faculty badge for authorized teachers.

3. 🛠️ Database Models Blueprint

User Schema Extension:

major: { type: String, enum: ['CSE', 'IT', 'ECE', 'ME', 'CE', 'BBA'], default: '' },
role: { type: String, enum: ['student', 'teacher', 'admin'], default: 'student' },
enrolledGroups: [{ type: Schema.Types.ObjectId, ref: 'Group' }]

Group Schema:

name: "CSE - Batch 2026",
major: "Computer Science & Engineering (CSE)",
admins: [TeacherUserIDs],
members: [StudentUserIDs]

4. 🔌 API Endpoints Specification

Method Endpoint Permission Description
POST /api/groups/auto-enroll Authenticated User Auto-assigns student to group based on Major & Year.
POST /api/assignments Verified Teacher Only Creates a new assignment with PDF attachment & deadline.
POST /api/assignments/submit/:id Enrolled Students Uploads student assignment solution file.

  1. Update User.js schema with standardized Major enum & roles.
